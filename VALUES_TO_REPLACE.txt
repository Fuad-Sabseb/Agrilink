📋 FIREBASE CONFIGURATION (AUTOMATED)
───────────────────────────────────────────────────────────────────────────

Don't manually replace - run this command instead:

  flutterfire configure --project=your-firebase-project-id

This will automatically create:
  - lib/firebase_options.dart (with all your Firebase keys)
  - android/app/google-services.json
  - ios/Runner/GoogleService-Info.plist

⚡ BACKEND CONFIGURATION (NOT IN APP)
───────────────────────────────────────────────────────────────────────────

Your backend server needs:

backend/.env file:
  FCM_SERVER_KEY=your_firebase_server_key_here
  DATABASE_URL=your_database_connection_string
  JWT_SECRET=your_jwt_secret_key

(Get FCM_SERVER_KEY from Firebase Console → Cloud Messaging → Server Key)
